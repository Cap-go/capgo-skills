# Live Activities (@capgo/capacitor-live-activities)

iOS Live Activities and activity push updates.

**Platforms:** iOS  
**Package:** `@capgo/capacitor-live-activities`

## Installation

```bash
npm install @capgo/capacitor-live-activities
npx cap sync
```

## Versions reviewed

`1.1.4` to `1.3.0` (since 2026-09-11).

## API delta in window

No new Promise methods in `definitions.ts` between these tags. Release `1.3.0` documents deprecation and removal sections in the changelog. Read the repository `CHANGELOG.md` before upgrading.

## Current API (reference)

Typical calls: `startActivity()`, `updateActivity()`, timer helpers such as `startTimerSequence()`, `getTimerState()`, `previousTimerStep()`, and `resumeTimerSequence()`. Exact shapes are in `src/definitions.ts` on tag `1.3.0`.
