# Watch (@capgo/capacitor-watch)

Apple Watch companion and Wear OS support.

**Platforms:** iOS, Android (Wear OS companion)  
**Package:** `@capgo/capacitor-watch`

## Installation

```bash
npm install @capgo/capacitor-watch
npx cap sync
```

## Versions reviewed

`8.1.3` to `8.1.20` (since 2026-09-11).

## Changes in window

No `definitions.ts` Promise method delta between these tags. Release `8.1.20` highlights **Wear OS** in documentation at the same level as Apple Watch. Follow the plugin README for Wear OS setup and asset generation (`@capacitor/assets` v4).
